# VoiceIME PRD Digest

> Source: docs/VoiceIME_PRD_v1.0.md | Version: V1.0 | Synced: 2026-05-21
> 本文件是 PRD V1.0 的压缩摘要。线框图、弹窗规格、交互细节请查阅源文档。

## 产品定位

个人专属本地语音输入法。运行在 Windows PC 上，核心诉求：随时按键说话，松开即上屏。100% 本地推理，零隐私泄露。

## 优先级分层

| 级别 | 含义 | 阶段 |
|------|------|------|
| P0 | 产品核心，无此功能不可用 | Phase 1 · MVP |
| P1 | 显著提升体验 | Phase 2 · 体验完善 |
| P2 | 差异化亮点，探索性 | Phase 3 · 智能化 |

## P0 功能清单

| 功能 | 关键规格 |
|------|---------|
| 全局热键录音 | Caps Lock keydown 开始 / keyup 停止；最短 200ms / 最长 60s；16kHz Mono |
| 系统托盘常驻 | 4 种状态（绿就绪/黄加载/红错误/灰暂停）；右键菜单含开关和跳转 |
| ASR 推理 | faster-whisper large-v3-turbo int8 CPU；VAD 默认开启；30s 超时 |
| 文本上屏 | 三层 Fallback: UIAutomation → 剪贴板+Ctrl+V → 逐字符；剪贴板保护 |
| 设置窗口 | 5 个 Tab: 推理引擎 / 热键配置 / 后处理 / LLM 接口 / 高级 |

## P1 功能清单

| 功能 | 关键规格 |
|------|---------|
| 文本后处理管道 | 标点规范化 → 繁简转换 → 热词替换 → LLM 润色(可选) |
| 热词词库管理 | 增删改查 + CSV 导入导出；触发词小写匹配；存 hotwords.json |
| 历史记录 | SQLite 本地存储；搜索 + 应用过滤 + 一键再次上屏 |

## P2 功能清单

| 功能 | 关键规格 |
|------|---------|
| 上下文感知 | 读取聚焦窗口进程名/标题，匹配规则表自动切换后处理行为和 LLM Prompt |

## 核心交互流程

```
按键 → 录音(悬浮条+波形) → 松开 → VAD裁剪 → ASR推理(识别中) → 结果确认条 → 上屏/润色/重录
```

快速模式：识别完成后跳过确认，直接上屏。

## LLM 润色规格

- 支持接口：Claude API / OpenAI API / 本地 Ollama
- 触发方式：悬浮条按钮 / 设置自动润色
- 超时 10s，超时保留原文
- API Key 用 keyring 存 Windows Credential Manager

## 性能目标

| 指标 | 目标 |
|------|------|
| 模型冷启动 | ≤ 8s |
| 二次唤醒 | < 100ms |
| 5s 音频推理 (CPU) | ≤ 2.5s |
| 内存占用 | ≤ 4 GB |
| 待机 CPU | < 1% |

## 安全与隐私

- 语音 100% 本地处理（LLM 润色除外）
- API Key 加密存储，不明文写配置
- 历史 SQLite 仅本地，不同步云端
- 进程崩溃时钩子必须自动注销

## 开发里程碑

| 阶段 | 周期 | 核心交付 |
|------|------|---------|
| Phase 1 MVP | 1-2 周 | 热键录音 + VAD + faster-whisper CPU + 剪贴板上屏 + 托盘图标 + 基础设置 |
| Phase 2 体验 | 2-3 周 | 悬浮条 UI + 热词词库 + 历史记录 + 繁简转换 + LLM 润色 + 内存锁定 |
| Phase 3 智能 | 1-2 周 | Vulkan 加速评估 + 上下文感知规则引擎 + 远程推理 API |

## 关键风险

| # | 风险 | 应对 |
|---|------|------|
| 1 | whisper.cpp Vulkan 780M 加速未实测 | Phase 1 后专项 benchmark |
| 2 | Caps Lock 全局拦截影响大小写习惯 | 提供热键更换入口 |
| 3 | VirtualLock 锁内存影响其他程序 | 上限 3.5GB + 关闭开关 |
