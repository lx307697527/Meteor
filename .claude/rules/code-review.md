# AI 代码审查清单

## 五讲：开发与审查底线

1. **讲规范**：禁止直接粘贴 AI 代码，必须符合项目编码规范
2. **讲注释**：复杂逻辑必须注释 Why（设计意图），非 What
3. **讲逻辑**：通读执行路径，剔除死代码和冗余条件
4. **讲安全**：零信任审查 — 禁止硬编码密钥，排查注入/XSS/越权
5. **讲效率**：评估复杂度，禁止为简单功能引入重型依赖

## 四美：代码交付质量标准

- **结构化**：高内聚低耦合，单一文件职责明确
- **自解释**：禁止 `data1`/`temp_list`/`obj` 等泛型命名，精准传达业务意图
- **健壮性**：边界条件与异常处理完备，防御性编程
- **纯净度**：移除所有调试残留（console.log/print/unused imports）
