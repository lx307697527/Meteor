# 提交纪律

## 单次提交上限
- 变更不超过 10 个文件或 500 行（以先到者为准）
- 超出必须拆分为多个提交，每个提交有独立的、可回滚的意图

## 提交前必须完成
- [ ] `python -m pytest` 全量通过
- [ ] 新增代码涉及的模块有对应测试覆盖
- [ ] 无临时调试代码残留 (`print()` / `breakpoint()` / `TODO HACK` / scratch scripts)
- [ ] 若涉及新功能或架构变更，PRD.md 和 Architecture.md 已同步更新

## 禁止混入提交
- 功能开发与 bug 修复不在同一提交
- 代码变更与文档更新可以同提交，但 commit message 必须体现两者
- 临时调试脚本禁止提交到主分支
