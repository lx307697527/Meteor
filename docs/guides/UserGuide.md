# VoiceIME 用户指南

> 版本：V1.0 | 适用于 Phase 1-3 全部功能

## 概述

VoiceIME 是一款 Windows 本地语音输入法。按下热键说话，松开即上屏。语音 100% 本地处理，零隐私泄露。

---

## 安装

### 方式一：下载安装包（推荐）

1. 从 Release 页面下载 `VoiceIME.exe`
2. 双击运行，首次启动自动进入**首次引导向导**
3. 向导将引导你完成：模型下载 → 热键测试 → 麦克风测试 → 完成

### 方式二：源码运行

```powershell
git clone <repo-url>
cd Meteor
pip install -r requirements.txt
python -m voiceime
```

### 系统要求

| 项 | 最低配置 | 推荐配置 |
|---|---------|---------|
| 操作系统 | Windows 10 64-bit | Windows 11 |
| 内存 | 8 GB | 16 GB+ |
| CPU | 4 核 | 8 核+（Intel 第 8 代或更新） |
| 磁盘 | 5 GB（模型文件约 3 GB） | SSD |

## 快速上手

### 第一次使用

1. **启动 VoiceIME** — 系统托盘出现绿色麦克风图标（就绪状态）
2. **打开任意文本输入框** — 记事本、Word、浏览器、IDE 均可
3. **按住 Caps Lock 说话** — 悬浮条显示录音波形
4. **松开 Caps Lock** — 语音识别完成后自动上屏

### 托盘图标状态

| 颜色 | 状态 | 含义 |
|------|------|------|
| 绿色 | 就绪 | 等待录音 |
| 黄色 | 加载中 | 模型加载或推理进行中 |
| 红色 | 错误 | 麦克风不可用 / 推理超时 |
| 灰色 | 已暂停 | 热键监听已暂停 |

### 右键菜单

右键点击托盘图标：

- **暂停/恢复**：临时关闭或开启热键监听
- **识别历史**：打开历史记录窗口
- **热词管理**：打开热词词库窗口
- **设置**：打开完整设置窗口
- **退出**：关闭 VoiceIME

---

## 悬浮条操作

录音结束后，悬浮条显示识别结果，提供以下操作：

| 按钮 | 功能 |
|------|------|
| 上屏（Enter） | 将文本输出到当前光标位置 |
| 润色 | 调用 LLM 对文本进行润色优化 |
| 重录 | 丢弃当前结果，重新录音 |
| 关闭（Esc） | 取消本次识别 |

### 快速模式

在设置中开启"快速模式"后，识别完成自动上屏，不显示确认悬浮条。配合上下文规则可根据应用自动切换该行为。

---

## 设置窗口

右键托盘 → **设置** 打开，共 5 个标签页：

### 推理引擎

- 模型选择（默认 large-v3-turbo）
- 计算设备（CPU / Vulkan 待验证）
- 推理线程数
- VAD 过滤开关

### 热键配置

- 录音热键（默认 Caps Lock）
- 可更换为其他按键组合

### 后处理

- 标点规范化
- 繁简转换
- 自动润色开关
- 热词替换开关

### LLM 接口

- API 类型：Claude API / OpenAI API / 本地 Ollama
- API 地址与密钥配置
- 密钥使用 Windows Credential Manager 加密存储
- 超时设置（默认 10s）
- 连接测试按钮

### 上下文（Phase 3）

- 上下文感知开关
- 规则表格：为不同应用配置不同的输入行为
- 每条规则可覆盖：快速模式、润色模式、系统提示词

---

## 上下文规则（Phase 3）

上下文规则允许你在不同应用中自动切换输入行为。

### 默认规则

| 规则名 | 应用 | 行为 |
|--------|------|------|
| VSCode 代码注释 | code.exe | 关闭快速模式，手动润色，使用代码注释提示词 |
| IDEA 代码注释 | idea64.exe | 同上 |
| 微信快速上屏 | wechat.exe | 开启快速模式，关闭润色 |
| Word 商务书面 | winword.exe | 自动润色，商务书面提示词 |
| WPS 商务书面 | wps.exe | 同上 |

### 自定义规则

在设置 → 上下文标签页中：

1. 点击 **添加** 创建新规则
2. 填写规则名称
3. 输入 `app_name_pattern`：进程名匹配（如 `chrome.exe`）
4. 可选 `title_pattern`：窗口标题匹配（如包含"邮件"时触发）
5. 勾选启用/禁用
6. 选择覆盖行为：快速模式、润色模式、系统提示词

规则按**列表顺序匹配**，首个匹配的规则生效。

## 热词词库

热词替换允许你定义"语音识别原文 → 替换为"的映射。

### 管理热词

右键托盘 → **热词管理** 打开窗口：

- **添加**：输入触发词和替换词
- **编辑**：修改已有热词
- **删除**：移除热词
- **导入 CSV**：从 CSV 文件批量导入
- **导出 CSV**：导出当前热词为 CSV

### 匹配规则

- 触发词**小写匹配**
- 匹配到触发词后替换为对应文本
- 在流水线中位于标点规范化之后、LLM 润色之前

---

## 识别历史

右键托盘 → **识别历史** 打开窗口：

- 按时间倒序显示所有识别记录
- 搜索框：按文本内容搜索
- 应用过滤：按来源应用过滤
- 一键再次上屏：点击历史条目完成上屏

所有数据存储在本地 SQLite 数据库，不同步云端。

## 常见问题

### 模型下载慢？

模型首次从 HuggingFace 下载（约 3 GB），下载速度取决于网络。可通过设置代理加速，或将已有模型目录复制到 `%APPDATA%\VoiceIME\models\`。

### 识别结果不准确？

- 确保麦克风正常，环境噪音尽量小
- 尝试调整 VAD 灵敏度（设置 → 推理引擎）
- 检查热词是否意外替换了文本

### Caps Lock 无法切换大小写了？

VoiceIME 接管了 Caps Lock 作为录音热键。可在设置 → 热键配置中更换为其他按键。

### 悬浮条不显示？

- 检查是否有其他程序遮挡
- 尝试重启 VoiceIME

### API 密钥存储在哪里？

使用 Windows Credential Manager（凭据管理器）加密存储，不在配置文件中明文保存。

```

API 类型：Ollama

模型：llama3
```

## 隐私说明

- 语音数据 100% 在本地处理，不发送到任何云端服务
- LLM 润色功能除外：启用时，文本内容会发送到你配置的 LLM API
- API 密钥使用 Windows Credential Manager 加密存储
- 识别历史仅存储在本地 SQLite 数据库
- 无任何遥测、埋点或用户行为追踪
